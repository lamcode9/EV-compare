How to work the list

One slot = one final file. PRIMARY is the intended shot; ALTERNATEs are different takes on the same slot — use them when the primary doesn’t land, or generate two or three and keep the best. Per slot:

  1. Paste the PRIMARY prompt into Grok Imagine (video mode), generate a few takes.
  2. Judge against the grade swatches above the prompt — the clip has to sit inside that act’s palette. Wrong palette beats wrong content: regenerate or try an alternate.
  3. Download the winner, run the two ffmpeg lines below (compress + poster), naming the output to the slot’s exact filename.
  4. Drop both files into public/sunrise/, reload /sunrise — the cel fades in on its own.

Slots are independent — ship them one at a time, in any order. Start with swarm and morning; they carry the most story.

Global spec (applies to every clip)

  • Format: 16:9, highest resolution Grok offers (page renders at ~1024px wide max). 6–10 seconds.
  • Loop-friendly motion: slow ambient drift only — smoke, embers, light shimmer, orbital glide. No camera cuts, no pans that start/stop, no zooms with a destination. Think “living painting”, not “trailer shot”.
  • No: text, watermarks, logos, readable faces, lens-flare kitsch, teal-and-orange grading, fast motion, birds/planes crossing frame (they break the loop).
  • Grade: each clip must sit inside its act’s sky palette (hexes per asset below) — the video is composited over a live canvas scene and must feel continuous with it, not pasted on.
  • Grain: neutral to slightly filmic. The page composites its own grain, so don’t over-grain the source.
  • Real-hardware anchors: name-check real hardware (“resembling a Starlink V3”, “resembling a Tesla Powerwall 3”, “JWST sunshield foil”) — it pulls the generator toward credible industrial design instead of generic sci-fi. Always keep the word resembling and the no-logos rule: the shape language, never the badge.

Post-processing (once clips are downloaded)

Strip audio, normalize, compress, and name into place. Target ≤ 8 MB per clip:

ffmpeg -i raw.mp4 -an -vf "scale=1920:-2" -c:v libx264 -crf 26 -preset slow \
  -movflags +faststart public/sunrise/fire.mp4

Poster frame (pick the best second):

ffmpeg -ss 2 -i public/sunrise/fire.mp4 -frames:v 1 -q:v 3 public/sunrise/fire.jpg

If a clip doesn’t loop cleanly, make a palindrome (works for embers/smoke/shimmer, not directional motion):

ffmpeg -i in.mp4 -filter_complex "[0:v]reverse[r];[0:v][r]concat=n=2:v=1[v]" \
  -map "[v]" -an -c:v libx264 -crf 26 -movflags +faststart out.mp4

Drop the files in, reload /sunrise, and each cel fades in on its own. Nothing else to wire.
