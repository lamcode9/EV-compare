Shoot for the whole frame

v4 supersedes every v3 prompt. The clips are no longer framed exhibits — each one is the full-viewport stage behind the words (see docs/one-cinematic-work-storyboard.html). That changes the brief in four ways, below. Slots marked AUDIT may already survive; run them through the three gates before reshooting. Slots marked REGENERATE were composed subject-centered for a box and need the full-bleed retake.

01 · What changed — the four full-bleed rules

Every prompt below already bakes these in

  1. Composition: subject right, words left. The reading column overlays the LEFT third; the bottom quarter carries a floor scrim. So: main subject weighted to the right two-thirds, left third falling into calm negative space (darkness for night scenes, soft haze for morning), bottom quarter quiet — no bright detail, no motion hotspots there.
  2. Seamless loop, stricter than before. Full-screen makes a loop seam ten times more visible than a box did. Locked tripod camera (or drift so slow it reads as stillness), no objects entering or leaving frame, end state ≈ start state.
  3. Highest resolution, 16:9 only. Generate at the largest size Grok offers. The clip covers a 1440px viewport and gets center-cropped to 9:16 on phones — which is why the subject must hold the center-right, never the far edges.
  4. Grade to the scene, not to taste. Each slot lists its grade hexes — they're the canvas sky's keyframe colors at that story beat, and the footage now shares frame edges with that canvas during cuts. Warmth belongs where the hexes say it does.
The three gates — audit before you reshoot

A surviving v3 take must pass all three at full-screen: ① Loop seam — play it looped for 30 seconds; any visible pop or drift fails. ② Text-safe left third — imagine white serif over the left third for the whole loop; any bright or busy patch that crosses it fails. ③ Calm floor — the bottom quarter stays dark and stable. Fail any gate → use the REGENERATE prompt.

Standing rules (unchanged from v3)
  • Real-hardware anchors: where the story references real machines, the prompt says "resembling" — a satellite bus resembling Starlink V3, storage blocks resembling Tesla Megapack, home units resembling Powerwall 3. Never logos, badges, or legible branding.
  • PRIMARY vs ALTERNATE: generate PRIMARY first (it's the storyboard's shot). ALTERNATE is a different composition of the same beat — use it when the primary take fights the grade or the gates, or generate both and pick the winner. Keep spares in ~/Developer/Battery.mom/videos/.
  • Drop-in contract: final files land at public/sunrise/<name>.mp4 + <name>.jpg poster. Page needs no code change — scenes light up when files land, and a missing file just leaves that scene on the canvas score.

03 · Encode + install

The pipeline (bumped for full-screen)

Full-bleed shows compression that a framed cel hid. CRF drops 23 → 20; keep the source resolution (never upscale); target ≤3.5 MB per clip.

# clip (from the raw Grok download)
ffmpeg -i raw.mp4 -an -c:v libx264 -crf 20 -preset slow -movflags +faststart -pix_fmt yuv420p public/sunrise/<name>.mp4

# poster (grab a mid-loop frame)
ffmpeg -ss 2 -i public/sunrise/<name>.mp4 -frames:v 1 -q:v 3 public/sunrise/<name>.jpg

Then reload /sunrise — no code change. Audit each new clip in place at desktop + 375px before deleting the spare takes from ~/Developer/Battery.mom/videos/.
